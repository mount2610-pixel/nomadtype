# NomadType

Монгол (кирилл) болон англи хэлээр хурдан шивэх чадвараа шалгах вэбсайт.

- Хоёр хэлээр бичих: **монгол** / **english** (бүтэн эсвэл богино үгийн сан), интерфейс **МН** / **EN**
- Горимууд: **хугацаа** (15 / 30 / 60 / 120 / өөрийн), **үг** (10 / 25 / 50 / 100 / өөрийн),
  **эх** (зүйр үг, дунд, урт өгүүллэг), **зэн** (чөлөөт бичих), **өөрийн текст**
- **@ цэг таслал**, **# тоо** нэмж хүндрүүлэх
- Үр дүн: хурд, нарийвчлал, түүхий хурд, тэмдэгт (зөв/буруу/илүү/орхисон), тогтвортой байдал,
  секунд бүрийн график, бичсэн үгсийн түүх, дээд амжилт, алдсан үгсээ давтах
- **Тохиргооны хуудас** (50 орчим тохиргоо): хүндрэл (энгийн/эксперт/мастер), хурдан дахин эхлэх,
  сохор горим, доод хурд/нарийвчлал, чөлөөт горим, алдаан дээр зогсох, итгэлийн горим, залхуу горим,
  дуу, курсорын хэлбэр, хурдны курсор, үсгийн хэмжээ, фонт, **гарын зураг** (монгол/англи байрлал),
  11 **загвар** (theme) г.м.
- **Командын мөр**: `Esc` эсвэл `Ctrl + Shift + P` — бүх тохиргоог гараас хайж солино
- "Миний амжилт" хуудас: дээд амжилтын хүснэгт, сүүлийн тестүүд, нийт хугацаа
- **Арван хуруугаар сурах** (📖): Монгол гарын 20, англи гарын 18 шаталсан хичээл. Хичээл бүр шинэ товч заана,
  гарын зураг дараагийн товчийг харуулна, тэнцвэл ★ од авч ахиц хадгалагдана
- **Premium хүлээлгийн жагсаалт**: "Premium удахгүй — имэйлээ үлдээ" (Firebase тохируулсан үед харагдана)
- Google-ээр нэвтэрч **дэлхийн жагсаалтад** орох (Firebase, заавал биш)

## 1. Компьютер дээрээ ажиллуулах

1. VS Code-оор `nomadtype` хавтсыг нээнэ (**File → Open Folder**).
2. **Live Server** өргөтгөл суулгана.
3. `index.html` дээр баруун товшоод **Open with Live Server**.

> `index.html`-ийг давхар товшиж нээсэн ч тест ажиллана. Гэхдээ нэвтрэх, жагсаалт зөвхөн
> Live Server эсвэл интернэтэд байршуулсан үед ажиллана.

## 2. Интернэтэд гаргах (GitHub Pages, үнэгүй)

1. https://github.com дээр `nomadtype` нэртэй шинэ repository үүсгэнэ.
2. Энэ хавтсын бүх файлыг оруулна (VS Code-ийн **Source Control** эсвэл GitHub сайтын **Upload files**).
3. Repository → **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, хавтас **/ (root)** → **Save**.
4. Хэдэн минутын дараа `https://<таны-нэр>.github.io/nomadtype/` хаягаар нээгдэнэ.

### Домэйн холбох
1. `CNAME` файлд өөрийн домэйноо бичнэ (жишээ `nomadtype.com`). Домэйнгүй бол `CNAME` файлыг **устгана**.
2. Домэйн худалдаж авсан газрынхаа DNS тохиргоонд:
   - `A` бичлэг: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `www` гэсэн `CNAME` бичлэг: `<таны-нэр>.github.io`
3. **Settings → Pages → Custom domain**-д домэйноо бичээд **Enforce HTTPS**-ийг асаана.

## 3. Дэлхийн жагсаалт асаах (Firebase, заавал биш)

1. https://console.firebase.google.com → **Add project** → нэр: `nomadtype`.
2. **Build → Authentication → Get started → Sign-in method → Google** → Enable.
3. **Authentication → Settings → Authorized domains** хэсэгт сайтынхаа домэйныг нэмнэ
   (`<таны-нэр>.github.io`, `nomadtype.com`). Live Server-ээр турших бол `127.0.0.1`-ийг ч нэмнэ.
4. **Build → Firestore Database → Create database** (Production mode, байршил: `asia-northeast3` Сөүл).
5. **Firestore → Rules** таб дээр `firestore.rules` файлын агуулгыг бүтнээр нь хуулж **Publish**.
6. **Project settings → Your apps → Web (</>)** → апп нэмээд гарч ирсэн `firebaseConfig`-ийн утгуудыг
   `js/firebase-config.js` файлд хуулна.
7. Файлуудаа дахин GitHub руу оруулна. Одоо толгой хэсэгт **Google-ээр нэвтрэх** товч гарч ирнэ.

Жагсаалтын дүрэм:
- Зөвхөн "хугацаа" горимын 15 / 30 / 60 секунд, бүтэн үгийн сан, цэг таслал, тоо, залхуу горимгүй тест.
  Хэл тус бүрт тусдаа жагсаалт. Толгой хэсгийн 👑 дүрс дээр дарж бүх жагсаалтыг харна.
- Нарийвчлал 90%-иас дээш, хурд 250 үг/минутаас бага.
- Хэрэглэгч бүр тест бүрт ганц мөртэй, зөвхөн өөрийн дээд амжилтаа шинэчилнэ.
- Жагсаалтад зөвхөн Google-ийн нэр харагдана, имэйл хэзээ ч харагдахгүй.

## Засварлах

| Юуг өөрчлөх | Аль файл |
| --- | --- |
| Шинэ үг, эх, зүйр үг нэмэх | `js/data.js` → `WORDS`, `PASSAGES`, `QUOTES` |

| Шинэ загвар (өнгө) | `js/config.js` → `THEMES` (нэг мөр нэмэхэд тохиргоо, командын мөрөнд автоматаар гарна) |

| Тестийн ажиллагаа | `js/test.js` |
| Гарын байрлал | `js/keymap.js` → `LAYOUTS` |
| Хичээл нэмэх, засах | `js/lessons.js` → `LESSONS` |

## Premium-ийн хүлээлгийн жагсаалт

Firebase тохируулсны дараа "Арван хуруугаар сурах" хуудас болон тестийн үр дүнгийн доор
"NomadType Premium удахгүй" гэсэн имэйл үлдээх форм гарна. Бүртгүүлсэн имэйлүүдийг
**Firebase Console → Firestore Database → `waitlist`** хэсгээс харна (тоо нь хэдэн хүн сонирхож байгааг харуулна).
Хэн ч бусдын имэйлийг уншиж чадахгүй (`firestore.rules`).
